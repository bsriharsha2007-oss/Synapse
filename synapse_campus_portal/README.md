# Synapse — Presidency University Campus Matchmaking & Admin Portal

## Multi-File Project Structure
- `index.html` — Semantic HTML5 shell for Authentication Gateway, Student Portal, Faculty Admin Portal, and interactive modals.
- `styles.css` — Dual Glassmorphism design system (Metallic Chic Light & Abyssal Dark), 3D tilt-card styling, and responsive grid layouts.
- `vault.js` — Client-side relational persistence engine (`SynapseVault` backed by `localStorage`) pre-seeded with Presidency University student, event, project, and circular records.
- `app.js` — Role-Based Access Control (RBAC), squad application & resume attachment workflows, CSV roster exporter, and Three.js 3D neural constellation animation.
